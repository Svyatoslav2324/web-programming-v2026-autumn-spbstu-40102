# Лабораторная работа 5

## Задание

Вариант 23. Создать список книг в магазине и реализовать переключение между
светлой и тёмной темами с помощью Context API без дизайн-библиотек.

Кнопка переключения расположена в правой верхней части страницы и меняет подпись
и иконку. Для цветов светлой темы заданы отдельные альтернативные цвета тёмной
темы.

## Реализация

Приложение создано на React и запускается с помощью Vite. Компонент
ThemeProvider хранит текущую тему в состоянии и передаёт её вместе с функцией
переключения через ThemeContext. Компонент ThemeToggle получает эти данные из
контекста, а BookStore отображает карточки книг.

Стили используют CSS-переменные: при смене класса корневого элемента значения
переменных заменяются на цвета тёмной темы. Список книг отмечен атрибутом
data-testid="book-list", кнопка темы — data-testid="theme-toggle", а корневой
элемент страницы — data-testid="app".

## Запуск

Выполните команды в каталоге лабораторной работы:

    npm install
    npm run dev

После запуска откройте адрес, который выведет Vite.
