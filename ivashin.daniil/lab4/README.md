# Лабораторная работа 4

## Задание

Вариант 23. Создать класс Game для хранения названия игры, списка платформ и
года выпуска. Реализовать методы работы с платформами и геттер количества
платформ. Реализовать операции группировки и поиска игр, пользовательский
интерфейс, асинхронные изменения и сохранение списка игр в localStorage.

## Реализация

В model.js находятся класс Game и пять функций работы с коллекцией:
groupGamesByReleaseYear, getUniquePlatforms, findGamesByPlatform,
groupGamesByPlatformCount и findGamesReleasedAfter.

Файлы index.html, styles.css и main.js создают форму добавления игры, карточки
игр и кнопки управления играми и платформами. После каждого изменения DOM и
localStorage обновляются автоматически. Все операции добавления и удаления
выполняются через Promise и setTimeout.

## Запуск

Из корня репозитория запустите:

    py -m http.server 8000

Откройте в браузере: http://localhost:8000
