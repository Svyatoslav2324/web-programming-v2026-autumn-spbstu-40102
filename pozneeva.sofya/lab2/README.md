# Лабораторная работа 2

## Задание

Вариант 16.

Реализовать функцию, которая проверяет, является ли строка изограммой (не имеет
повторяющихся букв, игнорируя регистр).

## Реализация

Алгоритм, который лежит в основе реализации функции:

1. Создаём пустой set, в который в дальнейшем при прохождении будут добавлятся
   одиночные буквы.
2. Проходимся циклом for по строке и проверяем, есть ли новый символ в сете,
   если нет - добавляем, если есть, возвращаем из функции false, не дожидаясь
   окончания цикла.
3. При завершении цикла, если функция так и не вернула значение false, то
   возвращаем true, были проверены все юуквы строки.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
