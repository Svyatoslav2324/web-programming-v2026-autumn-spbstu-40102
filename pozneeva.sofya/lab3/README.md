# Лабораторная работа 3

## Задание

Вариант 16.

Реализуйте функцию findEquilibriumIndex(arr), которая находит индекс, где сумма
левой и правой части массива равна.

## Реализация

Алгоритм, который лежит в основе реализации функции:

1. Считается сумма всего массива
2. Проходимся циклом for по массиву меняя сумму правой и левой части на каждой
   итерации и сравнивая их.
3. В случае существования необходимого индекса функция вернёт его значение, не
   закончив цикл. Иначе функция вернёт -1.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
