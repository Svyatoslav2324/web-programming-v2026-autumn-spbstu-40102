# Лабораторная работа 3

## Задание

Вариант 6. Реализуйте функцию intersection(arr1, arr2), которая возвращает
массив общих элементов.

## Реализация

Функция: intersection(arr1, arr2) → массив элементов, присутствующих в обоих
массивах (каждый один раз, в порядке первого массива). Экспорт: export function
intersection(arr1, arr2).

Алгоритм (O(n·m)): обходим arr1 через for...of; для каждого элемента проверяем
вхождение во второй массив arr2.includes(item); найденные общие элементы
складываем в Set — он автоматически убирает дубликаты; в конце множество
разворачиваем в массив ([...result]).

Граничные случаи:

1. один из массивов пуст (или оба) → [];
2. нет общих элементов → [];
3. дубликаты внутри массивов → в результат попадают один раз;
4. работает с любыми типами элементов (числа, строки), сравнение — строгое
   равенство.
