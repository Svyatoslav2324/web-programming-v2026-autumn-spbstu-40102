# Лабораторная работа 2

## Задание

Вариант 6. Написать функцию isPerfectNumber, проверяющую, является ли число
"совершенным" (сумма делителей равна числу, исключая само число).

## Реализация

Функция: isPerfectNumber(num) → boolean. true, если число равно сумме своих
собственных делителей. Экспорт: export function isPerfectNumber(num).

Алгоритм (O(√n)): итерация происходит до √num. Если num%i==0, добавляются оба
делителя пары. В конце сравнение суммы с num.

Граничные случаи:

1. num <= 1 → false.
2. num — полный квадрат. Делитель √num добавляется один раз.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
